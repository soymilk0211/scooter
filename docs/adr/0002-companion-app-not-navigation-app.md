# 本 App 是警示外掛，不是導航 App

原始 PRD 以 Mapbox 逐向導航為核心迴圈，警示條件之一是「路線引擎判定即將左轉」。此路線有三個問題：Mapbox Navigation SDK 免費額度僅 100 MAU（且模擬器與重裝各計一次），開源替代方案（MapLibre + Valhalla）需自行維運伺服器，而自建導航必須與 Google Maps 正面競爭品質。

改採**外掛模式**：本 App 不提供導航。騎士照常使用既有導航 App，本 App 以前景服務在背景監看位置與方位角，於接近已知路口規則時以懸浮視窗與語音警示。

此決定的前提是 ADR-0001 —— 既然規則掛在進入方位角上，判斷「騎士正沿某方向接近某路口」不需要路線，只需要 GPS。警示文案因此改為條件句（「前方路口左轉需待轉」），與現場標誌的語意一致：標誌並不知道你要不要左轉。

## Consequences

- 不需要路線引擎、不需要付費地圖導航授權、不需自架路線伺服器。
- 警示會在騎士無意左轉時也發出，噪音較高，需以「僅在有規則時警示」控制。
- 與 PRD「使用者會同時執行第三方測速 App」的前提一致 —— 本 App 本來就設計為與其他 App 併用。
