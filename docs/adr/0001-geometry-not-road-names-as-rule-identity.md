# 路口規則的身分由幾何決定，不由路名決定

原始 SDD 規劃以 `entry_road_name` + `exit_road_name` 字串比對來查找路口規則。台灣路名的表述變異過大（忠孝東路／忠孝東路三段／忠孝東路３段／`Zhongxiao E Rd Sec 3`；台1線／縱貫公路），且圖資供應商、政府開放資料與社群回報三方的命名不會一致，字串相等無法作為可靠的 join key。

因此規則的身分改為 **(路口座標, 進入方位角)**：以座標半徑內最近的路口節點加上方位角比對。方位角由任何一方計算都會得到相同結果，且完全不受命名影響。路名降級為反正規化的顯示欄位，供回報介面與除錯使用，**永遠不參與比對**。

## Consequences

- 資料庫需要地理空間索引，不能只靠字串索引。
- 路名可能顯示錯誤而不影響警示正確性；反之路名正確也不代表規則命中。
- 官方開放資料匯入時需要一道地理編碼步驟，把地址型資料轉成座標與方位角。
