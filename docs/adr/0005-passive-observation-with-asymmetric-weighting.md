# 被動觀察為主要資料來源，並以不對稱權重排除違規行為

主動回報依賴使用者熱情，冷啟動階段收不到足夠資料。改以**被動觀察**為主：待轉在 GPS 軌跡上有獨特特徵（直行穿越路口 → 停止 → 停留數十秒 → 原地轉約 90 度 → 起步），與直接左轉的平滑弧線可區分。資料來源因此從「願意按按鈕的少數人」擴大為「所有開著 App 騎車的人」。

被動觀察看到的是**行為**而非**規則**，違規的直接左轉會污染資料。解法是利用兩者的證據強度不對稱：

- **待轉行為是強證據** —— 沒有人自願待轉，因為它更慢更麻煩。觀察到待轉幾乎可確定該路口要求待轉。
- **直接左轉是弱證據** —— 可能合法，也可能違規。需要高得多的共識數才能成立規則。

官方資料另外充當守法測驗：在官方已確認**必須**待轉的路口，直接左轉的裝置即為違規者，其「直接左轉」觀察權重歸零，但「待轉」觀察仍然有效 —— 待轉行為本身不會說謊。

## Consequences

- 被動蒐集行為軌跡，隱私分量高於主動回報。必須預設開啟前明確告知並提供關閉選項；僅上傳單點觀察結果，不上傳原始軌跡。
- **守法分數不得落地儲存。** 一份「違規者名單」在法律上可被調取，對使用者與營運者皆是風險；守法分數只在裝置本機計算，或於伺服器端作為即時權重用完即棄。
- 主動回報退居糾錯用途。
